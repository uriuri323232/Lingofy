# Lingofy — לימוד אנגלית↔עברית אופליין

אפליקציית אנדרואיד (Kotlin + Jetpack Compose) ללימוד אוצר מילים. עובדת לגמרי בלי אינטרנט, בלי הרשאת INTERNET ובלי לשלוח נתונים לשום מקום.

## מה בפנים (גרסה 2.0)
- **296 מילים ב-13 קטגוריות** (בסיסי, משפחה, אוכל, בית, גוף, זמן, צבעים, נסיעות, טבע, טכנולוגיה, עבודה, תארים, מתקדמים). התרגומים נבדקו ותוקנו, וכפילויות הוסרו.
- **כרטיסיות עם אנימציית היפוך**, מעבר כיוון (אנגלית→עברית / עברית→אנגלית), והשמעה אוטומטית.
- **4 סוגי חידון**: אנגלית→עברית, עברית→אנגלית, האזנה, וכתיבה. 10 שאלות בסבב, עם סיכום.
- **חזרה מרווחת**: מילים חדשות וחלשות מופיעות יותר, ומילה שנטעתה חוזרת באותו סבב.
- **חיזוק מילים קשות**: סבב ייעודי למילים שטעית בהן.
- **המילה היומית**, **יעד יומי** (טבעת התקדמות), **רצף ימים** ורצף שיא.
- **חיפוש** באנגלית ובעברית עם סינון לפי קטגוריה, **מועדפים** עם תרגול ייעודי.
- **מסך התקדמות**: דיוק, התקדמות לפי קטגוריה, רשימת מילים קשות.
- **הגדרות**: מצב בהיר/כהה/לפי המערכת, יעד יומי, מהירות הקראה, איפוס התקדמות.
- אייקון אדפטיבי (בועת A + בועת א).

## בנייה
1. העלה את התיקייה ל-GitHub.
2. ב-Actions הפעל `Build Android APK` והורד את ה-artifact `Lingofy-debug-apk`.

או ב-Android Studio (JDK 17, Android 8.0+ / API 26).

## הרחבת המאגר
`app/src/main/assets/words.json` — אפשר להוסיף אובייקטים:
`{"en":"abandon","he":"לנטוש","category":"בסיסי"}`
כמה תרגומים מופרדים ב-` / ` (התרגום הראשון הוא הראשי בחידונים). קטגוריה חדשה תופיע אוטומטית; לאימוג׳י ולסדר שלה ראה `WordRepository.kt`.
