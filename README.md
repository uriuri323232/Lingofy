# מילים בכיף — VocabMaster Offline

אפליקציית לימוד אוצר מילים אנגלית↔עברית לאנדרואיד, עם ממשק מודרני ועבודה מלאה אופליין.

## מה בפנים
- מאגר מילים מקומי ב-JSON — אין צורך באינטרנט בזמן השימוש.
- כרטיסיות לימוד עם חשיפת תרגום.
- חידון אמריקאי עם 4 תשובות.
- חיפוש מהיר באנגלית ובעברית.
- קטגוריות: בסיסי, בית, אוכל, נסיעות, עבודה, טבע, טכנולוגיה ועוד.
- מועדפים.
- מערכת חזרה פשוטה: מילים חלשות חוזרות מוקדם יותר.
- סטטיסטיקות: נלמדו, הצלחות, רצף ויעד יומי.
- Text-to-Speech אופציונלי דרך מנוע הדיבור המותקן במכשיר; אינו נדרש להפעלת האפליקציה.
- מצב כהה.
- ללא הרשאת INTERNET במניפסט.
- GitHub Actions שבונה APK אוטומטית.

## בנייה ב-GitHub
1. העלה את כל התיקייה ל-repository.
2. ודא ש-Gradle מותקן או פתח ב-Android Studio.
3. ב-GitHub Actions הפעל `Build Android APK`.
4. הורד את ה-artifact בשם `vocabmaster-debug-apk`.

## דרישות
- Android Studio עדכני עם JDK 17.
- Android 8.0 ומעלה (API 26).

## הרחבת המאגר
קובץ המילים נמצא ב:
`app/src/main/assets/words.json`

אפשר להוסיף אובייקטים באותו מבנה:
`{"en":"abandon","he":"לנטוש","category":"בסיסי"}`

האפליקציה אינה שולחת את המילים לשום שרת.
